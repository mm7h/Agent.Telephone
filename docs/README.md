# Agent.Telephone 文档索引

本目录面向两类读者：需要部署电话 Agent 的运维/实施人员，以及需要接入模型、存储或 FunctionTool 的 .NET 开发者。

建议按以下顺序阅读：

1. [快速开始与部署](00-快速开始与部署.md)：准备资源、启动示例、完成第一通电话。
2. [HT701 网关配置与兼容性](01-HT701网关配置与兼容性.md)：把模拟电话接入 SIP/RTP 服务。
3. [配置文件参考](02-配置文件参考.md)：调整号码、模型、提示词和工具授权。
4. [系统架构与音频流水线](03-系统架构与音频流水线.md)：理解运行时生命周期与分层边界。
5. [FunctionTool 与按键交互扩展](04-FunctionTool与按键交互扩展.md)：增加 Assistant 能力。
6. [持久化、回拨与离线留言](05-持久化、回拨与离线留言.md)：实现可恢复的对话数据。
7. [Assistant 角色与业务场景](06-Assistant角色与业务场景.md)：组织前台、专用角色和通话内切换。
8. [故障排查与运维](07-故障排查与运维.md)：定位注册、音频、模型和回拨故障。
9. [安全、隐私与生产运行边界](08-安全、隐私与生产运行边界.md)：保护 SIP、密钥、通话与数据。
10. [项目目录、外部资源与内置提示音](09-项目目录、外部资源与内置提示音.md)：查找源码、模型、运行期目录和每个嵌入音频的用途。

## 文档版本边界

文档以当前仓库工作区为依据。示例已提供 `10088` Codex 任务助理：它通过 `codex exec --ephemeral` 运行非交互任务，不提供电话审批、追问或 Codex Thread 恢复。升级 Codex CLI 或发布前应重新核对对应示例与测试。

示例配置中的 API Key、Access Token 和电话号码均为占位值。不要把自己的凭据、录音、留言数据库或日志提交到仓库。
